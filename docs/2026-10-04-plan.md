# Project Plan: Progress Tracker PWA (2026-10-04)

## Architecture Decisions
- **Framework**: React (scaffolded via Vite for fast builds and HMR).
- **Styling**: Vanilla CSS to ensure maximum flexibility and adherence to the "rich aesthetics" requirement (dark mode, glassmorphism, micro-animations).
- **Data Storage**: IndexedDB for robust, asynchronous client-side storage, bypassing limits of LocalStorage.
- **PWA**: Use `vite-plugin-pwa` to quickly implement service workers and manifest files for offline capabilities.

## Phase 1: Setup and Foundation
1. **Initialize Project**: Use Vite to scaffold a new React project in the root directory.
2. **Configure PWA**: Install and configure `vite-plugin-pwa` for offline caching and installability.
3. **Set up Styling System**: Implement the foundational Vanilla CSS design system (color variables for curated dark mode palette, modern typography like 'Inter' or 'Outfit', glassmorphism utility classes).
4. **Initialize Storage**: Set up IndexedDB structure and create data access services for Goals and Check-ins.

## Phase 2: Core Logic & Services
1. **Goal Management**: API layer over IndexedDB to create, read, update, and delete goals.
2. **Check-In Logic**: API to record check-ins for specific dates and specific goals.
3. **Statistics Engine**: Create utility functions to calculate total progress, streaks, schedule adherence, and format data for the heatmap.

## Phase 3: User Interface Development (Mobile-First)
1. **Dashboard (Home)**:
    - Overview of active goals.
    - Quick check-in action buttons for today's scheduled items.
2. **Goal Detail View**:
    - **Heatmap Component**: Visual representation of activity history.
    - **General Track**: Progress bar for total progress towards the end goal (if it's a finite goal).
    - **Schedule Track**: Visualizing adherence to the specific schedule (e.g., current streak, check-in calendar).
3. **Goal Creation Flow**:
    - Form to define title, end-goal presence, and schedule frequency (daily, weekly, every n days, monthly).
4. **Settings/Data Management**:
    - Export data to JSON file.
    - Import data from JSON file.

## Phase 4: Polish and Aesthetics
1. **Micro-animations**: Add subtle transitions for interactions (hover states, form submissions, satisfying check-in completion animations).
2. **Responsive Adjustments**: Ensure all components are perfectly optimized for mobile touch targets while gracefully expanding on desktop.
3. **PWA Assets**: Generate and configure necessary icons, splash screens, and theme colors.
